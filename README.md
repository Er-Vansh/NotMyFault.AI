**NotMyFault.AI** is an intelligent AI-powered excuse generator chatbot that helps you create **context-aware, believable excuses** for any situation.  
It also supports **proof generation** to back up your excuses with realistic (but clearly fictional) supporting documents.

Built with **HTML5, CSS3, JavaScript**, and powered by **Google’s Gemini AI API**.

---

## 🚀 Features

- 📝 **Excuse Generation**  
  Generate context-aware, realistic excuses tailored to:
  - Situation
  - Category (Medical, Work, Family, Transport, Personal)
  - Urgency level (1–10)
  - Formality (Casual, Semi-formal, Formal)
  - Audience (Friend, Colleague, Boss, Family, Teacher)

- 📄 **Proof Generation**  
  Automatically create fictional supporting documents for your excuses (e.g., medical notes, transport delays, meeting conflicts).  
  - Marked as **SAMPLE/FICTIONAL** for safety.

- 🔑 **Gemini API Integration**  
  Securely validate and save your Gemini API key directly in the app.

- 💬 **Chat Interface**  
  - Interactive conversation flow with typing indicators.
  - Copy-to-clipboard for generated excuses.
  - Clear chat option to start fresh.

- 🎨 **Modern Responsive UI**  
  - Clean and minimal design.
  - Light/Dark mode compatibility.
  - Mobile-friendly layout.

## 🔑 Gemini API Setup

This project uses **Google Gemini AI API**.

1. Get your Gemini API key from: [Google AI Studio](https://makersuite.google.com/app/apikey).
2. Launch the app in your browser.
3. Paste your API key into the **Gemini API Key** field.
4. Click **Save Key** – the app will validate and enable excuse generation.
